# HireFlow

HireFlow is a production-style Recruitment and Applicant Tracking System (ATS).

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- React Query

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- PostgreSQL
- Prisma ORM

### Authentication
- JWT
- Refresh Tokens
- Google OAuth

### Security
- Argon2
- Helmet
- CORS
- Rate Limiting
- Input Validation

### Deployment
- Vercel
- Railway / Render
